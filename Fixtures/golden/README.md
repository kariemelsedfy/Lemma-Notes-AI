# Golden set

`AI_PIPELINE.md` §9: ≥200 real handwritten selections from ≥15 writers, distributed 40%
arithmetic/algebra, 20% calculus, 10% chemistry/physics notation, 15% prose continuation,
10% plots, 5% deliberate garbage the model must decline.

**What is here now is not that.** These six cases are a *shape fixture*: enough to exercise the
runner in CI, one per category, with the labels a real case carries. They contain no real
handwriting, no crops, and no writer's work — capturing that is M4-06B and needs a human with an
iPad and consent from fifteen people.

Do not read metrics produced from this directory as quality numbers. Read them as "the harness
runs". Against the stub provider the read accuracy is 100% by construction.

One JSON file per case, named by id so a diff between two runs lines up.
